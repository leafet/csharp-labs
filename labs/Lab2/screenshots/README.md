# Снимки запусков ЛР2

В `live/` находятся пять снимков результатов работы:

| Файл | Задания по условию |
| --- | --- |
| `task1.png` | 1.3 — Имена |
| `task2.png` | 2.2 и 2.3 — Человек с именем и родителем |
| `task3.png` | 3.3 — Города |
| `task4.png` | 4.5 и 4.6 — Конструкторы |
| `task5.png` | 5.2 — Кот мяукает |

Программа запущена в псевдотерминале с включённым отображением ввода. Номер, введённый пользователем, виден непосредственно после приглашения «Выберите задание». Снимки являются HTML-визуализацией текста экрана этого сеанса; соответствующий текст сохранён в `logs/`. Это не фотографии окна терминала.

Для повторения запустите `dotnet run --project CSharpLabs/CSharpLabs.csproj` из корня репозитория. Выберите лабораторную работу `2`, затем нужный пункт меню. После просмотра результата нажмите Enter для возврата в меню.

Отчёт оформлен по образцу ЛР1. Markdown ссылается на изображения, а HTML содержит встроенные копии и открывается отдельно от репозитория.
