# Снимки проверок ЛР2

В `live/` находятся 14 PNG-снимков журналов фактических запусков:

- `task1`–`task5` — все пять пунктов меню с примерами из условия;
- `check_names`, `check_people`, `check_cities`, `check_constructors`, `check_cat` — 21 дополнительная проверка классов;
- `menu_main`, `menu_lab2` — обработка неверных номеров и неверного формата ввода;
- `eof` — завершение потока ввода;
- `build` — сборка с предупреждениями как ошибками.

Это снимки HTML-представления сохранённого вывода, а не фотографии окна терминала. Программа и проверки действительно запускаются; их stdout и stderr сохраняются без редактирования в `logs/`. На снимках отдельно указаны входные данные (`\n` обозначает Enter). Снимки создаёт Chromium. Код завершения каждого запуска должен быть нулевым, а ожидаемые результаты проверяются автоматически до создания изображения.

Примеры запускаются с перенаправленным вводом и выводом, поэтому экран не очищается и программа не ожидает Enter между заданиями. Дополнительные случаи выполняются во временном проекте, который ссылается на основной проект. После проверки временный проект удаляется; в репозитории по-прежнему один проект C# и одна точка входа приложения.

## Воспроизведение

Из корня репозитория:

```bash
python3 labs/Lab2/tools/build_report.py
```

Необходимы .NET 10 SDK, Python 3 и Chromium. Если браузер называется иначе, задайте путь через переменную `REPORT_CHROMIUM`. Генератор запускает локальные HTML-страницы с отдельным временным профилем Chromium; сеть для создания снимков не нужна.

Скрипт обновляет журналы, снимки и обе версии отчёта. Фрагменты C# берутся непосредственно из исходников, а оформление HTML — из отчёта ЛР1. Markdown ссылается на PNG-файлы; HTML содержит встроенные копии изображений и может быть открыт отдельно от репозитория.
