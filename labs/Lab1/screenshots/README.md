# Снимки запусков

Отчёт в Markdown ссылается на 60 файлов в `screenshots/live/`: по три снимка для каждой из 20 задач. Суффикс `_a` обозначает пример из условия, `_b` и `_c` — дополнительные примеры.

Для «Дней недели» показаны ввод «четверг», неверный день «чг» и вывод с понедельника. Для «Угадайки» показаны три завершённых запуска с победой и числом попыток. Старый снимок `input_check.png` исключён после изменения проверки диапазонов.

Самостоятельный HTML-отчёт содержит копии используемых снимков внутри файла.
