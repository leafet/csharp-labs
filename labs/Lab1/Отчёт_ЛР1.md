## Задача 2. Сумма знаков

### Текст задачи

Дана сигнатура метода: `public int sumLastNums (int x);`
Необходимо реализовать метод таким образом, чтобы он возвращал результат сложения двух последних знаков числа, предполагая, что знаков в числе не менее двух.
Подсказки: `int x=123%10; // х будет иметь значение 3`, `int у=123/10; // у будет иметь значение 12`
Пример: x=4568, результат: 14

### Алгоритм решения

Берём последнюю цифру числа оператором `% 10`, прибавляем к результату, затем отбрасываем её целочисленным делением `x /= 10` и повторяем ещё раз. Цифра берётся по модулю через private-метод `OnesDigit`, поэтому метод работает и с отрицательными числами.

```csharp
public int sumLastNums(int x)
{
    int y = 0;

    y += OnesDigit(x);
    x /= 10;

    y += OnesDigit(x);

    return y;
}

private int OnesDigit(int x)
{
    int digit = x % 10;

    if (digit < 0)
    {
        digit = -digit;
    }

    return digit;
}
```

## Задача 8. Делитель

### Текст задачи

Дана сигнатура метода: `public bool isDivisor (int a, int b);`
Необходимо реализовать метод таким образом, чтобы он возвращал true, если любое из принятых чисел делит другое нацело.
Пример 1: a=3, b=6, результат: true
Пример 2: a=2, b=15, результат: false

### Алгоритм решения

Проверяются оба порядка деления: `a % b == 0` и `b % a == 0`. Перед каждым сравнением убеждаемся, что делитель не равен нулю. Приведение делимого к `long` защищает от переполнения при вычислении `int.MinValue % -1`: без него эта операция может вызвать `OverflowException`. Привести один операнд достаточно, чтобы операция выполнялась с типом `long`.

```csharp
public bool isDivisor(int a, int b)
{
    if (b != 0 && (long)a % b == 0)
    {
        return true;
    }

    if (a != 0 && (long)b % a == 0)
    {
        return true;
    }

    return false;
}
```

```csharp
public int lastNumSum(int a, int b)
{

}
```

```csharp
int result = ReadInt("Введите 1-е число: ");
for (int i = 2; i <= 5; i++)

    result = lastNumSum(result, next);
}

Console.WriteLine($"Итого {result}");
```

## Задача 6. Тройная сумма

### Текст задачи

Дана сигнатура метода: `public bool sum3 (int x, int y, int z);`
Необходимо реализовать метод таким образом, чтобы он возвращал true, если два любых числа (из трех принятых) можно сложить так, чтобы получить третье.
Пример 1: x=5, y=7, z=2, результат: true
Пример 2: x=8, y=-1, z=4, результат: false

### Алгоритм решения

Перебираются все три пары из трёх чисел: `x + y == z`, `x + z == y`, `y + z == x`. Проверки объединяются оператором `||` — если хотя бы одна выполнена, возвращается `true`. Перед сложением один операнд приводится к `long`, чтобы сумма вычислялась без переполнения `int`. Иначе, например, `int.MaxValue + 1` без проверки переполнения может превратиться в `int.MinValue` и дать ложное совпадение.

```csharp
public bool sum3(int x, int y, int z)
{
    return (long)x + y == z || (long)x + z == y || (long)y + z == x;
}
```

## Задача 8. Возраст

### Текст задачи

Дана сигнатура метода: `public String age (int x);`
Необходимо реализовать метод таким образом, чтобы он возвращал строку, в которой сначала будет число х, а затем одно из слов: год, года, лет. Слово "год" добавляется, если число х заканчивается на 1, кроме числа 11. Слово "года" добавляется, если число х заканчивается на 2, 3 или 4, кроме чисел 12, 13, 14. Слово "лет" добавляется во всех остальных случаях. Подсказка: оператор % позволяет получить остаток от деления.
Пример 1: x=5, результат: "5 лет"
Пример 2: x=31, результат: "31 год"
Пример 3: x=44, результат: "44 года"

### Алгоритм решения

Сначала проверяются последние две цифры возраста: если они от 11 до 14 — всегда «лет». Затем по последней цифре: 1 → «год», 2–4 → «года», 5–9 и 0 → «лет». Приведение к `long` перед `Math.Abs` позволяет безопасно обработать даже `int.MinValue`: его модуль не помещается в `int`.

```csharp
public string age(int x)
{
    long n = Math.Abs((long)x);
    long lastDigit = n % 10;
    long lastTwoDigits = n % 100;

    if (lastTwoDigits >= 11 && lastTwoDigits <= 14)
    {
        return $"{x} лет";
    }

    if (lastDigit == 1)
    {
        return $"{x} год";
    }

    if (lastDigit == 2 || lastDigit == 3 || lastDigit == 4)
    {
        return $"{x} года";
    }

    return $"{x} лет";
}
```

## Задача 10. Вывод дней недели

### Текст задачи

Дана сигнатура метода: `public void printDays (String x);`
В качестве параметра метод принимает строку, в которой записано название дня недели. Необходимо реализовать метод таким образом, чтобы он выводил на экран название переданного в него дня и всех последующих до конца недели дней. Если в качестве строки передан не день, то выводится текст "это не день недели". Первый день понедельник, последний – воскресенье. Вместо if в данной задаче используйте switch.
Пример 1: x="четверг", результат: четверг пятница суббота воскресенье
Пример 2: x="чг", результат: это не день недели

### Алгоритм решения

По названию дня `switch` находит его позицию в массиве дней, затем цикл `for` выводит все дни от найденного до последнего. Если названия в списке нет, выводится сообщение об ошибке. Конструкция `if` для выбора дня не используется.

```csharp
private readonly string[] _days =
{
    "понедельник", "вторник", "среда", "четверг", "пятница", "суббота", "воскресенье"
};

public void printDays(string x)
{
    int start = -1;

    switch (x.ToLower())
    {
        case "понедельник":
            start = 0;
            break;
        case "вторник":
            start = 1;
            break;
        case "среда":
            start = 2;
            break;
        case "четверг":
            start = 3;
            break;
        case "пятница":
            start = 4;
            break;
        case "суббота":
            start = 5;
            break;
        case "воскресенье":
            start = 6;
            break;
        default:
            Console.WriteLine("это не день недели");
            return;
    }

    for (int i = start; i < _days.Length; i++)
    {
        Console.WriteLine(_days[i]);
    }
}
```

```csharp
public int pow(int x, int y)
```

Подсказки: `int x=123%10; // х будет иметь значение 3`, `int у=123/10; // у будет иметь значение 12`
Пример 1: x=1111, результат: true
Пример 2: x=1211, результат: false

### Алгоритм решения

Запоминается последняя цифра числа, затем цифры по одной отбрасываются делением на 10 и сравниваются с первой. Цифры берутся по модулю, поэтому минус перед числом не влияет на результат. Приведение к `long` перед `Math.Abs` необходимо для случая `int.MinValue`, модуль которого выходит за диапазон `int`.

```csharp
public bool equalNum(int x)
{
    long n = Math.Abs((long)x);
    long lastDigit = n % 10;

    while (n > 0)
    {
        if (n % 10 != lastDigit)
        {
            return false;
        }

        n /= 10;
    }

    return true;
}
```

Дана сигнатура метода: `public void guessGame()`
Необходимо реализовать метод таким образом, чтобы он генерировал случайное число от 0 до 9, далее считывал с консоли введенное пользователем число и выводил, угадал ли пользователь то, что было загадано, или нет. Метод запускается до тех пор, пока пользователь не угадает число. После этого выведите на экран количество попыток, которое потребовалось пользователю, чтобы угадать число.
Пример: «Введите число от 0 до 9: 5», «Вы не угадали, введите число от 0 до 9: 9», «Вы угадали! Вы отгадали число за 2 попытки»

### Алгоритм решения

`Random` один раз загадывает число от 0 до 9. Цикл `while` читает варианты и считает попытки до тех пор, пока не будет введено загаданное число. Затем выводится количество попыток, а форма слова («попытка», «попытки», «попыток») подбирается по последней и последним двум цифрам этого числа.

```csharp
public void guessGame()
{
    Random random = new Random();
    int secret = random.Next(0, 10);
    int attempts = 0;

    while (true)
    {
        int answer;

        if (attempts == 0)
        {
            answer = ReadInt("Введите число от 0 до 9: ", 0, 9);
        }
        else
        {
            answer = ReadInt("Вы не угадали, введите число от 0 до 9: ", 0, 9);
        }

        attempts++;

        if (answer == secret)
        {
            break;
        }
    }

    Console.WriteLine("Вы угадали!");

    int lastDigit = attempts % 10;
    int lastTwoDigits = attempts % 100;
    string word = "попыток";

    if (lastTwoDigits < 11 || lastTwoDigits > 14)
    {
        if (lastDigit == 1)
        {
            word = "попытка";
        }
        else if (lastDigit >= 2 && lastDigit <= 4)
        {
            word = "попытки";
        }
    }

    Console.WriteLine($"Вы отгадали число за {attempts} {word}");
}
```

## Задача 2. Поиск последнего значения

### Текст задачи

Дана сигнатура метода: `public int findLast (int[] arr, int x);`
Необходимо реализовать метод таким образом, чтобы он возвращал индекс последнего вхождения числа x в массив arr. Если число не входит в массив – возвращается -1.
Пример: arr=[1,2,3,4,2,2,5], x=2, результат: 5

### Алгоритм решения

Массив обходится с конца: первое найденное совпадение и есть последнее вхождение, его индекс и возвращается. Если совпадений нет, метод возвращает -1, и меню печатает сообщение об отсутствии числа.

```csharp
public int findLast(int[] arr, int x)
{
    for (int i = arr.Length - 1; i >= 0; i--)
    {
        if (arr[i] == x)
        {
            return i;
        }
    }

    return -1;
}
```

## Задача 4. Добавление в массив

### Текст задачи

Дана сигнатура метода: `public int[] add (int[] arr, int x, int pos);`
Необходимо реализовать метод таким образом, чтобы он возвращал новый массив, который будет содержать все элементы массива arr, однако в позицию pos будет вставлено значение x.
Пример: arr=[1,2,3,4,5], x=9, pos=3, результат: [1,2,3,9,4,5]

### Алгоритм решения

Позиция проверяется: допустимы значения от 0 до длины массива включительно. Создаётся массив на один элемент больше: в него копируется часть исходного массива до указанной позиции, затем вставляется новое значение, затем дозаполняется остаток.

```csharp
public int[] add(int[] arr, int x, int pos)
{
    if (pos < 0 || pos > arr.Length)
    {
        throw new ArgumentOutOfRangeException(nameof(pos));
    }

    int[] result = new int[arr.Length + 1];

    for (int i = 0; i < pos; i++)
    {
        result[i] = arr[i];
    }

    result[pos] = x;

    for (int i = pos; i < arr.Length; i++)
    {
        result[i + 1] = arr[i];
    }

    return result;
}
```

## Задача 6. Реверс

### Текст задачи

Дана сигнатура метода: `public void reverse (int[] arr);`
Необходимо реализовать метод таким образом, чтобы он изменял массив arr. После проведенных изменений массив должен быть записан задом-наперед.
Пример: arr=[1,2,3,4,5], результат: arr=[5,4,3,2,1]

### Алгоритм решения

Меняются местами парные элементы: первый с последним, второй с предпоследним — и так до середины массива.

```csharp
public void reverse(int[] arr)
{
    int left = 0;
    int right = arr.Length - 1;

    while (left < right)
    {
        int temp = arr[left];
        arr[left] = arr[right];
        arr[right] = temp;

        left++;
        right--;
    }
}
```

## Задача 8. Объединение

### Текст задачи

Дана сигнатура метода: `public int[] concat (int[] arr1, int[] arr2);`
Необходимо реализовать метод таким образом, чтобы он возвращал новый массив, в котором сначала идут элементы первого массива (arr1), а затем второго (arr2).
Пример: arr1=[1,2,3], arr2=[7,8,9], результат: [1,2,3,7,8,9]

### Алгоритм решения

Создаётся массив длиной, равной сумме длин, и в него по очереди копируются оба исходных массива.

```csharp
public int[] concat(int[] arr1, int[] arr2)
{
    int[] result = new int[arr1.Length + arr2.Length];

    for (int i = 0; i < arr1.Length; i++)
    {
        result[i] = arr1[i];
    }

    for (int i = 0; i < arr2.Length; i++)
    {
        result[arr1.Length + i] = arr2[i];
    }

    return result;
}
```

## Задача 10. Удалить негатив

### Текст задачи

Дана сигнатура метода: `public int[] deleteNegative (int[] arr);`
Необходимо реализовать метод таким образом, чтобы он возвращал новый массив, в котором записаны все элементы массива arr кроме отрицательных.
Пример: arr=[1,2,-3,4,-2,2,-5], результат: [1,2,4,2]

### Алгоритм решения

Первым проходом подсчитывается, сколько элементов останется после удаления отрицательных. Вторым проходом только они и копируются в новый массив. Так не приходится менять размер существующего массива.

```csharp
public int[] deleteNegative(int[] arr)
{
    int count = 0;

    for (int i = 0; i < arr.Length; i++)
    {
        if (arr[i] >= 0)
        {
            count++;
        }
    }

    int[] result = new int[count];
    int index = 0;

    for (int i = 0; i < arr.Length; i++)
    {
        if (arr[i] >= 0)
        {
            result[index] = arr[i];
            index++;
        }
    }

    return result;
}
```

# Проверка ввода

Задачи с вводом с клавиатуры читают данные через `ReadInt`, `ReadTwoDigitInt`, `ReadChar` и `ReadArray`. Числа вне диапазона `int`, недопустимые значения и ввод вместо одного символа нескольких отклоняются с повторным запросом. В `ReadTwoDigitInt` число приводится к `long` перед `Math.Abs`, чтобы проверка количества цифр работала и для `int.MinValue`. При завершении потока ввода программа завершается с сообщением «Ввод завершён».

Для номера меню разрешены 0–20; для задачи 1.2 — целые числа минимум с двумя цифрами; для возраста — 0–2147483647; для обратного списка — 0–1000; для показателя степени — 0–1000 при результате в диапазоне `int`; для высоты треугольника — 1–50; для «Угадайки» — 0–9; для позиции вставки — 0–`arr.Length`. Массив вводится непустым списком целых чисел. В остальных задачах принимается полный диапазон `int`, поскольку проверка знака, деления на ноль или неверного дня является частью самой задачи.
