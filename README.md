# Лабораторная работа № 1 — C#

Решены чётные задачи № 2, 4, 6, 8 и 10 из каждого из четырёх разделов [задания](lab1_csharp.pdf): всего 20 задач. Исходный PDF оставлен в репозитории для сверки условий.

## Состав

- [Отчёт в Markdown](Отчёт_ЛР1.md) — исходный отчёт со ссылками на снимки запусков.
- [Отчёт в HTML](Отчёт_ЛР1.html) — самостоятельный файл со встроенными снимками.
- [Решение Visual Studio](CSharpLabs.sln) и [проект .NET 8](CSharpLabs/CSharpLabs.csproj).
- [Контрольный сценарий](tools/verify_lab1.py) — проверка всех 20 задач и крайних случаев.

Номера 1–20 в консольном меню соответствуют порядку задач в отчёте. В заголовках отчёта указаны номера задач из PDF.

## Запуск и проверка

```powershell
dotnet build CSharpLabs.sln
dotnet run --project CSharpLabs/CSharpLabs.csproj
python tools/verify_lab1.py
```

Нужны .NET 8 SDK и Python 3 для контрольного сценария. Дополнительные пакеты для C# проекта и контрольного сценария не требуются. Для пересборки HTML из Markdown:

```powershell
python tools/make_report_standalone.py
```

Реальные снимки запусков находятся в `screenshots/live/`. Снимки случайной игры «Угадайка» из первоначального отчёта не подтверждали победу, поэтому в итоговом отчёте её результат удостоверяет воспроизводимая проверка в `tools/verify_lab1.py`.

Метод `pow(int x, int y)` рассчитан на неотрицательный показатель и результат, представимый типом `int`; отрицательная степень и переполнение не заданы в условии PDF.
