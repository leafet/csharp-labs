# Лабораторная работа № 1 — C#

Решены чётные задачи № 2, 4, 6, 8 и 10 из каждого из четырёх разделов [задания](lab1_csharp.pdf): всего 20 задач. Исходный PDF оставлен в репозитории для сверки условий.

## Состав

- [Отчёт в Markdown](Отчёт_ЛР1.md) — исходный отчёт со ссылками на снимки запусков.
- [Отчёт в HTML](Отчёт_ЛР1.html) — самостоятельный файл со встроенными снимками.
- [Решение Visual Studio](CSharpLabs.sln) и [проект .NET 10](CSharpLabs/CSharpLabs.csproj).

Номера 1–20 в консольном меню соответствуют порядку задач в отчёте. В заголовках отчёта указаны номера задач из PDF.

Ввод ограничен допустимыми диапазонами для каждой задачи. Автосвойства, LINQ-запросы и лямбда-операторы не используются. Форматирование и имена собственных полей, переменных и вспомогательных методов следуют [рекомендациям Microsoft](https://learn.microsoft.com/dotnet/csharp/fundamentals/coding-style/coding-conventions). Имена 20 публичных методов оставлены такими, как в обязательных сигнатурах PDF.

## Запуск

```powershell
dotnet build CSharpLabs.sln
dotnet run --project CSharpLabs/CSharpLabs.csproj
```

Нужен .NET 10 SDK. Дополнительные пакеты для C# проекта не требуются.

Реальные снимки запусков находятся в `screenshots/live/`. Снимки случайной игры «Угадайка» из первоначального отчёта не подтверждали победу, поэтому в итоговом отчёте описан контрольный запуск с перебором чисел от 0 до 9.

Метод `pow(int x, int y)` принимает неотрицательный показатель и проверяет переполнение `int`. В консольном меню результат вне диапазона `int` вызывает повторный запрос чисел.
