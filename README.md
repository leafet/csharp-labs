# Лабораторные работы по C#

В репозитории один проект .NET 10 — [CSharpLabs.csproj](CSharpLabs/CSharpLabs.csproj) — и одна точка входа, [Program.Main](CSharpLabs/Program.cs). Главное меню позволяет выбрать лабораторную работу. Код каждой работы находится в своей папке внутри проекта, а задания, отчёты и снимки запусков — в соответствующей папке `labs`.

В ЛР2 классы объектов находятся в папках соответствующих заданий. Общие классы `PersonFullName` и `Person` находятся в `Task1_Names` и `Task2_People`. Всё меню ЛР2, примеры заданий и сценарии ручного ввода собраны в одном классе `Lab2` в файле `Lab2/Lab2.cs`. Задания 4.5 и 4.6 используют конструкторы этих же классов. Статический класс `ConsoleInput` рядом с `Program` проверяет ввод для главного меню и ЛР2.

## Запуск

Из корня репозитория:

```bash
dotnet build CSharpLabs.sln
dotnet run --project CSharpLabs/CSharpLabs.csproj
```

Нужен .NET 10 SDK. В главном меню введите `1`, `2` или `3`; `0` завершает программу. Для новой работы добавьте классы в `CSharpLabs/LabN`, материалы в `labs/LabN` и пункт выбора в `Program.Main`. Новый проект и новая точка входа не нужны.

В меню ЛР2 пункты 1–5 выводят примеры из условия, созданные из объектов. В обычном терминале экран очищается при переходе между меню; результат задания остаётся на экране до нажатия Enter. При перенаправлении ввода или вывода очистка и пауза отключены. Ввод номеров меню проверяется. Автосвойства, LINQ и лямбда-операторы не используются.

Для ручного ввода в меню ЛР2 выберите `6`, затем тип объекта. Можно ввести ФИО, человека с необязательным отцом, города с направленными путями или кота. Для человека доступны строковое имя и объект ФИО. Любую отдельную часть ФИО можно пропустить, но хотя бы одна должна быть заполнена. Полностью пустое ФИО отклоняется как при создании, так и при изменении свойств. Без личного имени отца отчество не формируется. Пустые обязательные строки, неверные числа, неположительный рост и стоимость, пути в себя и повторные пути отклоняются с повторным запросом. Методы создания объектов собраны в статическом классе `ObjectInput`, чтение и проверка отдельных значений — в `ConsoleInput`.

В ЛР3 пункты `1`–`8` запускают примеры всех восьми заданий варианта 3; пункт `9` — ручной ввод. Класс `Matrix` содержит единственное поле — двумерный массив, конструкторы заполнения, поиск блока 3×3, транспонирование и перегруженные операторы для Aᵀ + 2B + Cᵀ. Статический класс `FileTasks` работает с бинарными и текстовыми файлами; массивы структур багажа записываются в бинарный контейнер с XML-сериализацией. Автосвойства, LINQ и лямбда-выражения не используются.

Файлы ЛР3 создаются в `labs/Lab3/data/` относительно текущего каталога. Примеры используют `new Random(3)` для воспроизводимости. Изображения в отчёте визуализируют настоящий вывод программы, а не интерактивные снимки терминала. В отчёт включён настоящий снимок проверки задания 3 в онлайн-калькуляторе MatrixCalc.
