В ЛР2 классы объектов находятся в папках соответствующих заданий. Общие классы `PersonFullName` и `Person` находятся в `Task1_Names` и `Task2_People`. ## Запуск

Из корня репозитория:

```bash
dotnet build CSharpLabs.sln
dotnet run --project CSharpLabs/CSharpLabs.csproj
```

Нужен .NET 10 SDK. В главном меню введите `1`, `2`, `3` или `4`; `0` завершает программу. В меню ЛР4 пункты `1`–`5` запускают задания с вводом данных.

Задания 6–7 ЛР4 запускаются командой `dotnet run --project Lab4.Points/Lab4.Points.csproj`. Выберите `1` для ввода координат и значений свойств точки.

В меню ЛР2 пункты 1–5 выводят примеры из условия, созданные из объектов. В обычном терминале экран очищается при переходе между меню; результат задания остаётся на экране до нажатия Enter. При перенаправлении ввода или вывода очистка и пауза отключены. Ввод номеров меню проверяется. Автосвойства, LINQ и лямбда-операторы не используются.

Для ручного ввода в меню ЛР2 выберите `6`, затем тип объекта. Можно ввести ФИО, человека с необязательным отцом, города с направленными путями или кота. Для человека доступны строковое имя и объект ФИО. Любую отдельную часть ФИО можно пропустить, но хотя бы одна должна быть заполнена. Полностью пустое ФИО отклоняется как при создании, так и при изменении свойств. Без личного имени отца отчество не формируется. Пустые обязательные строки, неверные числа, неположительный рост и стоимость, пути в себя и повторные пути отклоняются с повторным запросом. Методы создания объектов собраны в статическом классе `ObjectInput`, чтение и проверка отдельных значений — в `ConsoleInput`.

В ЛР3 пункты `1`–`8` запускают задания с вводом параметров, пункт `9` — отдельные демонстрации с готовыми данными. Меню находится в `Lab3.cs`. Общие классы `Lab3Input`, `Lab3Files`, `Matrix`, `FileTasks`, `BaggageItem` и `Passenger` перенесены в папку `Common` и пространство имён `CSharpLabs.Lab3.Common`; чтение параметров выполняет `Lab3Input`. Запуск и вывод каждого задания выделены в отдельный класс `Task1`–`Task8` в папке `Tasks`. В `Task1.Run()` явно запрашиваются размеры `n` и `m`, затем `new Matrix(n, m)` читает элементы с клавиатуры по столбцам. Готовые примеры всех восьми заданий вынесены в `RunExample()`, методы `Run` выполняют задания. Общий каталог данных подготавливает `Lab3Files.GetDataPath`. Класс `Matrix` содержит единственное поле — двумерный массив, конструкторы заполнения, поиск блока 3×3, транспонирование и перегруженные операторы для Aᵀ + 2B + Cᵀ. Статический класс `FileTasks` работает с бинарными и текстовыми файлами; массивы структур багажа записываются в бинарный контейнер с XML-сериализацией. Автосвойства, LINQ и лямбда-выражения не используются. В ЛР3, общих классах ввода и главном меню объявления рабочих переменных вынесены перед циклами; в телах выполняются присваивания. Счётчики for и переменные foreach остаются в заголовках циклов.

Файлы ЛР3 создаются в `labs/Lab3/data/` относительно текущего каталога. Обычные запуски используют `Random.Shared`; демонстрации — `new Random(3)` для воспроизводимости. В задании 1 первая матрица n×m вводится с клавиатуры, вторая n×n заполняется случайно, третья n×n — по рисунку. Во всех трёх используется одно n, равное числу строк первой матрицы. В заданиях 4, 6 и 7 вводятся параметры заполнения, сами числа генерируются случайно. Изображения в отчёте показывают реальные транскрипты ввода и вывода: введённые значения видны после приглашений. Оформление повторяет ЛР2; это визуализация сеанса, а не снимки окна терминала. Генератор использует вспомогательный проект tools/Lab3Transcript для эха ввода; код заданий остаётся в единственном основном проекте. Полные транскрипты сохранены в labs/Lab3/screenshots/logs. В отчёт включён настоящий снимок проверки задания 3 в онлайн-калькуляторе MatrixCalc.

Проверка способов заполнения и обработки данных ЛР3 после сборки: `python tools/check_lab3_assignment.py`. Проверяются общий размер n, рисунок третьей матрицы, диапазоны случайных чисел, содержимое файлов и граничные значения параметров.

В заданиях 6–8 текстовые файлы явно обрабатываются через StreamReader и StreamWriter. Чтение содержимого для вывода также выполняет StreamReader в методе FileTasks.ReadText; исходные строки задания 8 записывает FileTasks.FillTextLines через StreamWriter.
