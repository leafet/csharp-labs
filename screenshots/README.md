# Снимки запусков

Отчёт в Markdown ссылается на 57 файлов в `screenshots/live/`: по три снимка для 19 задач. Суффикс `_a` обозначает пример из условия, `_b` и `_c` — дополнительные примеры.

Для задачи «Угадайка» исходные три снимка были сделаны до завершения игры и исключены из итогового отчёта. Старый снимок `input_check.png` тоже исключён после изменения проверки диапазонов. Завершение игры, количество попыток и отклонение значений вне диапазона проверяет `python tools/verify_lab1.py`.

Самостоятельный HTML-отчёт содержит копии используемых снимков внутри файла. Его можно пересобрать командой `python tools/make_report_standalone.py`.
